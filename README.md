# Book Recommendation System

A Flask-based web application that recommends books using Python, Pandas, and Scikit-learn.

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS

## Features
- Book recommendation system
- Cosine similarity algorithm
- Dataset handling using Pandas
- Flask web application
- Frontend using HTML & CSS

## Machine Learning
Implemented recommendation logic using:
- CountVectorizer
- Cosine Similarity
